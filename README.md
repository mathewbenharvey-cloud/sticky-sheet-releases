# Sticky Sheet

A spreadsheet that behaves like a sticky note.

[Website](https://stickysheet.com) · [Windows downloads and matching source](https://github.com/mathewbenharvey-cloud/sticky-sheet-releases/releases) · [Feedback](https://stickysheet.com/#feedback)

This repository distributes official release files. Each binary release includes its matching source archive, build instructions, dependency notices, and SHA-256 checksums. Sticky Sheet is GPL-3.0-only; dependencies retain their own licenses.

The current Windows Tauri alpha is unsigned. It installs as Sticky Sheet Tauri Preview with a separate saved workspace from the older Electron app. Read the release instructions before migrating your notes. The [Mac Tauri preview](https://stickysheet.com/mac) is now available for Apple Silicon and Intel. Interactive acceptance testing is still in progress; it is not Apple-notarized.

Use the explicitly named **Sticky-Sheet-0.2.20-Tauri-source.zip** asset for the application source. GitHub’s automatic “Source code” snapshots contain this download repository’s README and license, not the application.
